# GOD Mode add-ons repository

Home Assistant add-on repository hosting **GOD Mode** — centralized
homelab monitoring native to HA. Add this URL to HA Settings → Add-ons
→ Add-on Store → ⋮ → Repositories:

```
https://github.com/hirofairlane/ha-god-mode
```

## Add-ons in this repo

- [`god_mode/`](god_mode/) — the GOD Mode add-on itself. See its
  [README](god_mode/README.md) for setup.
